Brand

Logo, mark & the core idea.

Logo lockup

my-wallet

The mark: a rounded gold tile with a punched-out coin slot. Use the mark alone for the app icon & favicon; the full lockup in headers and auth.

Principles

Calm, premium, confident.
Deep warm-black canvas, generous space, one gold accent. Money should feel handled, not loud.
Numbers are the hero.
Amounts use a monospace face with tabular figures so columns align and scanning is effortless.
Color carries meaning.
Gold = brand. Green = income. Coral = expense. Neon = data only. Never decorative.

07

Panda CSS mapping

Drop the tokens into panda.config.ts. Same names, same values.

// panda.config.ts — theme.tokens
colors: {
  gold: { 500: { value: 'oklch(0.80 0.118 87)' } },
  neon: { 500: { value: 'oklch(0.84 0.15 185)' } },
  income:  { value: 'oklch(0.72 0.15 157)' },
  expense: { value: 'oklch(0.645 0.185 26)' },
},
fonts: {
  display: { value: 'Sora, sans-serif' },
  sans: { value: '"Plus Jakarta Sans"' },
  mono: { value: '"JetBrains Mono"' },
},
radii: {
  md: { value: '14px' },
  lg: { value: '18px' },
  xl: { value: '24px' },
},
// theme.semanticTokens — resolve per theme
colors: {
  bg:      { value: { base: '{colors.n.975}',
                      _light: '{colors.n.50}' } },
  surface: { value: { base: '{colors.n.950}',
                      _light: '{colors.white}' } },
  text:    { value: { base: '{colors.n.50}',
                      _light: '{colors.n.900}' } },
  primary: { value: { base: '{colors.gold.500}',
                      _light: '{colors.n.900}' } },
  accent:  { value: { base: '{colors.gold.400}',
                      _light: '{colors.gold.700}' } },
},
// then: css({ bg: 'bg', color: 'text' })

Recipes (button, input, card, chip, badge) live in recipes.ts — class names in this doc match recipe variant names, so the mapping is mechanical. The full token source is in styles/tokens.css and a ready panda.config.ts ships in the project root.
