# Spec: Project Setup — Dependencies Migration

## Goal

Migrate the project from Tailwind CSS to Panda CSS and add all missing dependencies required by the project stack: Zustand, Vitest, Storybook, and Plop.

## Scope

**Included:**

- Remove Tailwind CSS and all related config files
- Add and configure Panda CSS with Next.js preset
- Add Zustand with `devtools` + `persist` (localStorage) middleware in store boilerplate
- Add Vitest with `jsdom` environment and `@testing-library/react`
- Add Storybook with `@storybook/nextjs` builder
- Add Plop with `pnpm plop` script in `package.json`

**Out of scope:**

- Migrating existing component styles from Tailwind to Panda CSS (no components exist yet)
- Writing actual tests or stories (covered by plop generators spec)
- Creating Zustand stores (covered by plop generators spec)

## Implementation steps

### 1. Remove Tailwind

- Uninstall: `tailwindcss`, `@tailwindcss/postcss`
- Delete: `tailwind.config.*`, `postcss.config.*`
- Remove Tailwind directives (`@tailwind base/components/utilities`) from any global CSS files

### 2. Add Panda CSS

- Install: `@pandacss/dev`
- Create `panda.config.ts`:

  ```ts
  import { defineConfig } from "@pandacss/dev";

  export default defineConfig({
    preflight: true,
    presets: ["@pandacss/preset-base", "@pandacss/preset-panda"],
    include: ["./src/**/*.{ts,tsx}", "./app/**/*.{ts,tsx}"],
    exclude: [],
    outdir: "styled-system",
  });
  ```

- Add `prepare` script: `"prepare": "panda codegen"`
- Add `styled-system/` to `.gitignore`
- Add Panda CSS PostCSS plugin to `postcss.config.mjs` (or create it):
  ```js
  export default {
    plugins: {
      "@pandacss/dev/postcss": {},
    },
  };
  ```
- Import Panda CSS in global CSS: `@layer reset, base, tokens, recipes, utilities;`

### 3. Add Zustand

- Install: `zustand`
- No config files required — boilerplate handled by plop generator

### 4. Add Vitest

- Install (devDependencies): `vitest`, `@vitejs/plugin-react`, `@testing-library/react`, `@testing-library/jest-dom`, `jsdom`
- Create `vitest.config.ts`:

  ```ts
  import { defineConfig } from "vitest/config";
  import react from "@vitejs/plugin-react";

  export default defineConfig({
    plugins: [react()],
    test: {
      environment: "jsdom",
      globals: true,
      setupFiles: ["./vitest.setup.ts"],
    },
  });
  ```

- Create `vitest.setup.ts`:
  ```ts
  import "@testing-library/jest-dom";
  ```
- Add test script to `package.json`: `"test": "vitest"`

### 5. Add Storybook

- Init: `pnpm dlx storybook@latest init --type nextjs`
- Verify builder is `@storybook/nextjs` in `.storybook/main.ts`
- Add storybook scripts to `package.json`:
  - `"storybook": "storybook dev -p 6006"`
  - `"build-storybook": "storybook build"`

### 6. Add Plop

- Install (devDependencies): `plop`
- Create empty `plopfile.ts` (populated by plop generators spec `001`)
- Add script to `package.json`: `"plop": "plop"`

---

## Edge cases & error states

- `styled-system/` must be in `.gitignore` — it is auto-generated by `panda codegen`
- Storybook init may add its own PostCSS config — verify it does not conflict with Panda CSS PostCSS plugin
- `vitest` and `jest` types may conflict — use `globals: true` in vitest config and avoid installing `@types/jest`
